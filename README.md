# Nova CRM Dashboard

## Project Overview

Nova CRM is a web-based Client Relationship Management dashboard designed for digital agencies to manage leads, clients, tasks, and business activities from a centralized platform.

## Problem Statement

Many agencies still manage operations using spreadsheets and disconnected tools, leading to:
- Missed follow-ups
- Poor lead visibility
- Scattered client information
- Reduced productivity

The goal was to design a scalable CRM dashboard that improves workflow management.
